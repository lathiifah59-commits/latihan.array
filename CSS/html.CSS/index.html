CSS (Cascading Style Sheets)

1. Apa Itu CSS?

CSS adalah bahasa stylesheet yang digunakan untuk mengatur tampilan dan tata letak halaman web.

Dengan CSS kita dapat mengatur warna, ukuran font, jarak, background, dan berbagai tampilan lainnya.
